# لودي — Lodi

فيديو كرتوني عمودي (1080×1920، تيك توك) من 6 مشاهد عن «لودي»، مشجع هلالي يلبس طقم الأهلي ويروح الملعب عشان بس يكون ضد النصر.

| # | المشهد | الصوت |
|---|---|---|
| 1 | الاعتراف — غرفة النوم، جالس على السرير (طقم الهلال) | `public/audio/s1.mp3` |
| 2 | الدولاب — يدفن طقم الهلال ويطلع طقم الأهلي | `public/audio/s2.mp3` |
| 3 | المرآة — بطقم الأهلي كامل | `public/audio/s3.mp3` |
| 4 | السيارة ليلاً — التذكرة ٨٠ ريال و٧٠ كم | `public/audio/s4.mp3` |
| 5 | المدرجات — بين جماهير الأهلي | `public/audio/s5.mp3` |
| 6 | الختام — خارج الملعب وحده | `public/audio/s6.mp3` |

## الملفات
- `prep.py` — يقرأ ملفات الصوت ونصوص المشاهد، يحدد مقاطع الكلام، يوزّع الكلمات عليها (للترجمة المتزامنة)، ويحسب حركة الفم. يكتب `src/data.json`.
- `src/Lodi.tsx` — الشخصية (شعر مجعد، نظارة، طقمين، تعابير، جلوس/وقوف/مشي، حركة الفم).
- `src/scenes.tsx` — المشاهد الستة. `src/ui.tsx` — شريط الترجمة والملصقات. `src/Video.tsx` — الانتقالات.

## التشغيل
```bash
python3 prep.py          # بعد أي تغيير في الصوت أو النص
npm i
npx remotion studio      # معاينة
npx remotion render Lodi Lodi_v1.mp4
```
لتعديل نص الترجمة: عدّل `SCENES` في `prep.py` ثم شغّله من جديد.
