# خادم مشاركة التقارير (رموز QR)

يحفظ نسخة من كل تقرير في ملف الإنجاز ويعيدها لمن يمسح رمز QR.
المعلم لا يرى هذا الخادم ولا يُدخل أي شيء: الأداة ترسل جلسة دخوله الحالية تلقائياً،
والخادم يتحقق منها (قراءة فقط، دون أي تعديل على قاعدة البيانات).

الرابط المطبوع في الرمز يكون على نطاق الأداة نفسها: `https://نطاق-الأداة/?r=رمز`.
لذلك يمكن نقل التخزين لاحقاً دون أن تتعطل الرموز المطبوعة.

## النشر (مرة واحدة، حوالي 10 دقائق)

1. أنشئ حساباً مجانياً في Cloudflare.
2. من لوحة التحكم: **R2 Object Storage** ← فعّل الخدمة (الخطة المجانية 10 GB) ←
   أنشئ حاوية باسم `enjaz-shared-reports`. تبقى الحاوية **خاصة** (لا تفعّل الوصول العام).
3. على جهازك داخل هذا المجلد:
   ```bash
   npm install
   npx wrangler login
   npx wrangler deploy
   ```
   ستظهر رسالة فيها عنوان الخادم، مثل `https://enjaz-share.<اسمك>.workers.dev`.
4. (مُستحسن) اربط نطاقاً فرعياً خاصاً بك من **Workers ← enjaz-share ← Settings ← Domains**
   مثل `api.نطاقك.com`، حتى لا يظهر اسم المزوّد حتى في أدوات المطوّر.
5. في `wrangler.toml` ضع نطاق الأداة في `ALLOWED_ORIGINS` (مثلاً `https://enjaz.example.com`)
   ثم `npx wrangler deploy` مرة أخرى.
6. في `index.html` ضع عنوان الخادم:
   ```js
   const PF_SHARE_API = 'https://api.نطاقك.com';
   ```
   ما دام فارغاً تعمل الأداة كما هي ويُصدَّر ملف الإنجاز بدون رموز QR.

## الواجهة

| الطلب | من | الوظيفة |
|---|---|---|
| `POST /v1/reports` | المعلم المسجّل | رفع حتى 3 تقارير ← `{ ids: { مفتاح_التقرير: رمز } }` |
| `GET /v1/r/:id` | أي أحد | محتوى تقرير واحد (بدون هوية المالك) |
| `DELETE /v1/r/:id` | مالك التقرير فقط | حذف التقرير من الاستضافة |

- رمز كل تقرير ثابت للمعلم نفسه من أي جهاز، فتعديل التقرير لا يغيّر رمزه المطبوع.
- الحد الأعلى لكل معلم `MAX_REPORTS_PER_USER` (افتراضياً 500).
- يقبل الخادم الحقول المعروفة فقط، والصور بصيغة صورة فقط (JPEG/PNG/WebP).

## التكلفة

الخطة المجانية: 10 GB تخزين (حوالي 100 ألف تقرير بصورتين مضغوطتين)، و100 ألف طلب يومياً للخادم،
وبدون رسوم على التحميل مهما كثر مسح الرموز.

## تجربة محلية

```bash
npx wrangler dev   # يحاكي الحاوية محلياً
```
